# Contributing

Thanks for your interest in HAILE! Contributions are welcome.

## Getting Started

1. Fork the repository
2. Create a feature branch: `git checkout -b my-feature`
3. Make your changes
4. Test locally (see [README.md](README.md) for setup instructions)
5. Commit with a clear message: `git commit -m "Add: short description"`
6. Push and open a Pull Request

## Guidelines

- Keep changes focused — one feature or fix per PR
- Follow existing code style (see `.editorconfig`)
- Test both SSE and Realtime modes if your change touches the chat pipeline
- Don't commit secrets or `local.settings.json`

## Reporting Issues

Open a GitHub issue with:
- What you expected vs. what happened
- Steps to reproduce
- Browser / OS / Python version
